# Weatherly

A clean, responsive weather dashboard built with vanilla HTML, CSS, and JavaScript. The interface is in Uzbek and adapts to desktop and mobile screens.

## Features

- Current conditions and a 7-day forecast
- Hourly forecast and sunrise/sunset times
- Air-quality readings
- City search, recent searches, and saved cities
- Celsius/Fahrenheit switch
- Light and dark themes
- Open-Meteo geocoding and forecast data; no API key required

## Run locally

Open `index.html` in a modern browser. For local development, you can also serve the folder with any static HTTP server.

## Data sources

- Weather and geocoding: [Open-Meteo](https://open-meteo.com/)
- Air quality: CAMS ENSEMBLE via Open-Meteo

## Project files

- `index.html` — page structure and accessible controls
- `style.css` — responsive layout and themes
- `script.js` — weather requests and dashboard interactions
